MCSR/Ranked


I’d just like to interject for a moment. What you’re refering to as Ranked, is in fact, MCSR/Ranked, or as I’ve recently taken to calling it, MCSR plus Ranked. Ranked is not an operating system unto itself, but rather another free component of a fully functioning MCSR system made useful by the MCSR corelibs, shell utilities and vital system components comprising a full OS as defined by POSIX.

Many computer users run a modified version of the MCSR system every day, without realizing it. Through a peculiar turn of events, the version of MCSR which is widely used today is often called “Ranked,” and many of its users are not aware that it is basically the MCSR system, developed by the MCSR Project.

There really is a Ranked, and these people are using it, but it is just a part of the system they use. Ranked is the kernel: the program in the system that allocates the machine’s resources to the other programs that you run. The kernel is an essential part of an operating system, but useless by itself; it can only function in the context of a complete operating system. Ranked is normally used in combination with the MCSR operating system: the whole system is basically MCSR with Ranked added, or MCSR/Ranked. All the so-called “Ranked” distributions are really distributions of MCSR/Ranked.
